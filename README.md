# Roblox Multiplayer Tennis (Luau + Rojo)

Полная архитектура, спецификация и пошаговые инструкции для ИИ-агентов по созданию мультиплеерной игры в теннис на платформе Roblox.

---

## 🎯 О проекте

Проект реализует соревновательную теннисную игру (формат 1v1 с архитектурной поддержкой 2v2):
- **Детерминированная сетевая физика**: вместо непредсказуемой стандартной физики Roblox используется аналитический расчет траекторий ($\mathbf{P}(t) = \mathbf{P}_0 + \mathbf{V}_0 t + \frac{1}{2}\mathbf{g} t^2$) с авторитетным сервером и клиентским сглаживанием на `RenderStepped`. Полное отсутствие дерганий мяча при любом пинге!
- **Правила большого тенниса (ITF)**: система очков `Love -> 15 -> 30 -> 40 -> Deuce -> Advantage -> Game -> Set -> Tie-break`, отслеживание касаний корта и сетки, квадраты подачи (Deuce / Ad), ауты и двойные ошибки.
- **Интуитивное управление**: камера от третьего лица из-за спины игрока, шкала тайминга удара (Early / Good / Perfect / Late), выбор типов удара (Flat, Topspin, Slice, Lob, DropShot) и направление прицеливания.
- **Модульная структура для ИИ-агентов**: вся игра разбита на 10 автономных задач в каталоге `docs/tasks/`. Каждая задача содержит строгие контракты типов Luau, формулы, алгоритмы и готовый скрипт верификации.

## 🤖 Как использовать эти инструкции с ИИ-агентом

Инструкции созданы специально так, чтобы даже относительно легкая модель (например, Claude 3.5 Haiku, Gemini Flash, GPT-4o-mini) могла безошибочно реализовать весь проект:

1. **Шаг 1**: Откройте `docs/AGENT_SYSTEM_PROMPT.md` и передайте его как системную инструкцию вашему ИИ-агенту.
2. **Шаг 2**: Передавайте агенту задачи **строго по порядку** от `task-01` до `task-10`:
   - Скопируйте текст из `docs/tasks/task-01-project-setup.md`.
   - Дождитесь завершения генерации кода и проверки встроенным тестом верификации.
   - Переходите к следующей задаче (`task-02-...`).
3. **Почему это работает**:
   - Каждая задача затрагивает только 1-2 конкретных файла.
   - Каждая задача содержит жестко зафиксированные типы данных Luau.
   - ИИ-агенту не нужно «додумывать» архитектуру сетевого взаимодействия или формулы параболы — все формулы и алгоритмы уже расписаны по шагам.

## 🚀 Сборка и запуск в Roblox Studio

### Требования:
- Установленный [Rojo](https://rojo.space/) (v7.3+)
- Roblox Studio с плагином Rojo

### Команды:
1. **Сборка файла плейса (.rbxl)**:
   ```bash
   rojo build -o Tennis.rbxl
   ```
2. **Живая синхронизация с запущенной Roblox Studio**:
   ```bash
   rojo serve
   ```
   В Roblox Studio нажмите **Connect** в плагине Rojo. Все изменения файлов в папке `src/` мгновенно появятся в дереве Explorer.
